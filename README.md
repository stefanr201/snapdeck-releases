# SnapDeck for Windows

SnapDeck is a small Windows tray utility that centers the focused window without
resizing it, cycles through windows belonging to the focused app, and minimizes
all windows belonging to the focused app.

## Download SnapDeck

**[Download the SnapDeck installer for Windows x64](https://github.com/stefanr201/snapdeck-releases/releases/latest/download/SnapDeck-1.4.1-Setup.exe)**

The installer adds SnapDeck to the Start menu and Windows' installed-apps list.
It does not create a desktop shortcut unless you select that option.

[Download the portable ZIP](https://github.com/stefanr201/snapdeck-releases/releases/latest/download/SnapDeck-1.4.1-Windows-x64.zip)

[View release notes and previous versions](https://github.com/stefanr201/snapdeck-releases/releases/latest)

For the portable version, extract the ZIP and run `SnapDeck.exe`.

The default shortcuts are **Win + Alt + C** to center a window, **Alt + Z** to
cycle through windows of the same app, and **Alt + X** to minimize all windows
of that app. Double-click the tray icon to change any shortcut or other setting.
Window actions are paused while the focused app is fullscreen.

## Windows security

Windows prevents normal applications from moving windows that run as Administrator.
Start SnapDeck as Administrator only when you need to control another elevated app.

This repository contains release notes and compiled binaries only. It does not
contain SnapDeck's source code.
