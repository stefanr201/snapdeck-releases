# SnapDeck for Windows

SnapDeck is a small Windows tray utility that centers the focused window without
resizing it.

## Download

Download the current Windows x64 ZIP from the repository's **Releases** page,
extract it, and run `SnapDeck.exe`.

The default shortcut is **Win + Alt + C**. Double-click the tray icon to open
Settings and change the shortcut, startup, theme, tray behavior, or icon style.

## Windows security

Windows prevents normal applications from moving windows that run as Administrator.
Start SnapDeck as Administrator only when you need to control another elevated app.

This repository contains release notes and compiled binaries only. It does not
contain SnapDeck's source code.
